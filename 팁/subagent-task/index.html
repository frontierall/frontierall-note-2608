시스템 가드가 특정 파일명 패턴을 차단할 수 있음

analysis.md 같은 흔한 리포트성 파일명 패턴은 서브에이전트의 Write 시도가 샌드박스 가드에 막힐 수 있다. 이럴 때 에이전트는 저장 대신 전체 내용을 응답으로 반환하도록 지시해두면, 오케스트레이터(메인 세션)가 대신 저장하면 된다 — 사전에 "저장 실패 시 전체 내용을 응답으로 반환하라"는 지시를 에이전트 프롬프트에 넣어두는 게 안전하다.

병렬 실행 + 결과 확인

  • 여러 개 독립 작업(영상 분석 등)은 한 메시지에서 Agent를 동시에 여러 번 호출하면 병렬로 돈다.
  • 백그라운드 에이전트의 전체 transcript를 직접 읽지 말고(컨텍스트 폭발), 완료 알림의 result 요약과 산출물 파일 존재 여부만 확인한다.
