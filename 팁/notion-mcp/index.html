데이터베이스 생성

notion-create-database는 SQL DDL 문법을 쓴다. 예:

CREATE TABLE (
  "제목" TITLE,
  "채널" SELECT('a':blue, 'b':green),
  "상태" SELECT('완료':yellow, '진행중':blue),
  "글자수" NUMBER,
  "업로드일" DATE
)

STATUS 타입보다 SELECT가 커스텀 옵션 이름·색을 지정하기 편하다 (칸반 보드 그룹핑에도 그대로 쓸 수 있음).

뷰(보드/테이블) 추가

notion-create-view는 database_id와 data_source_id를 둘 다 요구한다. 하나만 넘기면 Exactly one of database_id or parent_page_id must be provided 에러가 난다 — 얼핏 봐선 원인 파악이 안 되는 에러 메시지이니 주의.

data_source_id 형식

create-pages의 parent.data_source_id는 bare UUID만 받는다. fetch·create-database 응답에 나오는 collection://xxxx-xxxx-... 형태 URL을 그대로 넣으면 should be a valid uuid 에러가 난다 — collection:// 접두사를 떼고 UUID만 넘길 것.

페이지 안에 코드 블록(복사하기 편한 박스) 넣기

마크다운 트리플 백틱(```text ... ```)으로 감싸면 Notion에서 언어 선택 드롭다운 + 복사 버튼이 있는 박스로 렌더링된다. 긴 텍스트(대본 전문 등)를 통째로 복사해가기 편하게 만들 때 유용하다.
