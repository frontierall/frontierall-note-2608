보호 구역이 있는 프로젝트에서 "항상 이렇게 해줘"를 시키는 법

출처 · 08_autoworker02

문제

배포본 보호 구역(예: .claude/skills/, prompts/, scripts/, 루트 문서 CLAUDE.md·README.md·CHANGELOG.md·VERSION)이 있는 저장소는 "업데이트해줘"/"초기화해줘"를 실행하면 이 파일들이 배포본 zip 내용으로 통째로 덮어써진다. 즉 여기에 자동화 규칙을 적어 넣어도 다음 업데이트에서 사라진다.

해결

파일을 고치는 대신 Claude의 memory 시스템(~/.claude/projects/{프로젝트}/memory/)에 "feedback" 타입 메모리로 규칙을 저장한다.

  • 저장소 파일이 아니므로 초기화·업데이트에 영향받지 않는다.
  • 다음 세션에서도 Claude가 스스로 불러와서 적용한다.
  • 단, 이 계정·이 로컬 환경에서 Claude Code로 작업할 때만 적용된다. 다른 컴퓨터·다른 사람이 같은 저장소를 열면 적용되지 않는다 — 저장소에 내장된 게 아니라 Claude 쪽 개인 설정이기 때문.

적용 판단 기준

"이 저장소를 누가 열어도 항상 이래야 한다" → 저장소 파일에 넣어야 하는데, 보호 구역이라 불가능하면 학생 커스터마이징 허용 파일(channels/{채널}/config/profile.md 등)을 찾아본다.

"나(이 계정)의 작업 습관으로 항상 이래야 한다" → memory가 적합하다.
