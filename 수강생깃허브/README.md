# 수강생 깃허브

수업 중에 본인이 직접 공유한 GitHub 계정을 모아 둔 곳입니다.
[index.html](index.html)이 대표 진입 파일이고, 명단은 [members.js](members.js) 한 곳에만 있습니다.

공개 페이지: https://frontierall.github.io/frontierall_note_2608/수강생깃허브/

## 이름을 가리는 이유

이 저장소는 GitHub Pages로 **누구나 볼 수 있게** 공개되어 있습니다.
그래서 이름은 가운데 글자를 `O`로 바꿔 적습니다.

| 실제 | 페이지에 적는 값 |
| --- | --- |
| 세 글자 이름 | 첫 글자 + `O` + 끝 글자 (예: `김O재`) |
| 두 글자 이름 | 첫 글자 + `O` (예: `황O`) |

GitHub 아이디는 본인이 이미 공개해 둔 것이라 그대로 씁니다.
**목록에서 빼 달라고 하면 언제든 지웁니다.** 강사에게 말씀하시거나 직접 지우고 커밋하시면 됩니다.

## 사람 추가하기

`members.js`의 `MEMBERS` 배열에 객체 하나만 더하면 됩니다.
카드·검색·인원수는 `index.html`이 알아서 그립니다. HTML은 건드릴 필요가 없습니다.

```js
{
  name: '홍O동',              // 필수. 가운데 글자를 가린 이름
  gh: 'hongildong',           // 필수. GitHub 아이디
  repo: 'my-project',         // 선택. 특정 저장소를 공유했을 때만
  repos: 7,                   // 선택. 공유 시점의 공개 저장소 개수
  note: '한 줄 메모',          // 선택
},
```

| 항목 | 설명 |
| --- | --- |
| `name` | 화면에 보이는 이름. 위 규칙대로 가려서 적습니다. |
| `gh` | GitHub 아이디. 프로필 주소 `https://github.com/{gh}` 와 아바타 이미지를 이 값으로 만듭니다. |
| `repo` | 대표 저장소 이름. 넣으면 카드 링크가 프로필 대신 그 저장소로 갑니다. |
| `repos` | 공개 저장소 개수. 시간이 지나면 틀려지므로 화면에도 "공유 시점 기준"이라고 적어 둡니다. |
| `note` | 본인이 덧붙인 말. 예: "Private으로 해 둔 것이 많습니다." |

맨 위 `MEMBERS_UPDATED` 는 명단을 정리한 날짜입니다. 크게 손볼 때 함께 고쳐 주세요.

## 왜 JSON이 아니라 .js 인가

`.json` + `fetch` 는 HTML 파일을 더블클릭해서 여는 로컬 환경(`file://`)에서
CORS 정책에 막혀 읽히지 않습니다. `.js` 로 두면 로컬과 GitHub Pages 양쪽에서
똑같이 동작합니다. 같은 이유로 [용어사전](../용어사전)도 `terms.js` 를 씁니다.

`index.html`은 `members.js?t=<현재시각>` 으로 불러옵니다.
파일을 고쳤는데 브라우저가 옛 내용을 보여 주는 일을 막기 위한 것입니다.

## 아바타가 안 보일 때

아바타는 `https://github.com/{아이디}.png` 를 그대로 씁니다.
아이디를 잘못 적었거나 네트워크가 막히면 이미지가 사라지고 회색 원만 남습니다.
이때는 `gh` 값의 철자를 먼저 확인하세요.
