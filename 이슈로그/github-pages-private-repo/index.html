GitHub Pages

GitHub Pages가 Private 저장소에서 동작하지 않음

출처 · 프론티어올 러닝 노트

증상

저장소를 Private 상태로 두고 GitHub Pages를 켜려 하면 활성화가 거부된다. 무료 개인 플랜은 Private 저장소에 대해 Pages를 지원하지 않는다. (Pro/Team/Enterprise 플랜에서만 Private 저장소 Pages 지원)

해결

공개해도 문제없는 내용인지 커밋 이력 전체를 아래 명령으로 훑어 민감 파일 유무를 먼저 확인했다.

git log --all --diff-filter=A --name-only --pretty=format: | sort -u | grep -iE "token|secret|password|\.env"

문제가 없는 것을 확인한 뒤 저장소를 Public으로 전환하고, Pages API로 활성화했다.

gh repo edit OWNER/REPO --visibility public --accept-visibility-change-consequences
gh api -X POST repos/OWNER/REPO/pages -f "source[branch]=main" -f "source[path]=/"

이후 https://OWNER.github.io/REPO/로 정상 공개를 확인했다.
