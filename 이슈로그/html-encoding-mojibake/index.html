HTML · 인코딩

교안 HTML에 문서 구조가 없어 한글이 깨짐

출처 · 프론티어올 러닝 노트

증상

일부 교안 파일이 <!DOCTYPE html>·<head>·<meta charset="UTF-8"> 없이 본문 태그(<h1> 등)로 바로 시작하는 조각 형태였다. 브라우저가 인코딩을 잘못 추측해 한글 전체가 깨진 문자로 표시됐다.

해결

완전한 HTML5 문서 구조를 갖추고 사이트 공통 디자인 톤으로 다시 작성했다.

<!DOCTYPE html>
<html lang="ko">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>...</title>
</head>
<body>
  ...
</body>
</html>

이후 새로 추가하는 교안 파일은 항상 이 구조를 기본 템플릿으로 사용한다.
