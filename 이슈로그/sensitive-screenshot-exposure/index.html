보안 · Git

교안 폴더에 민감한 원본 스크린샷이 함께 있을 위험

출처 · 프론티어올 러닝 노트

증상

Supabase Personal Access Token, Google OAuth 클라이언트 보안 비밀번호가 찍힌 화면 캡처가 교안 자료 폴더 주변에 함께 존재했다. 그대로 커밋하면 저장소가 Public으로 전환됐을 때 자격 증명이 노출될 수 있었다.

해결

실제 교안에 삽입된 이미지는 토큰·비밀번호 값이 이미 블러 처리되어 있는 것을 하나씩 열어 직접 확인했다. 원본 미편집 스크린샷 폴더는 .gitignore에 추가해 애초에 커밋 대상에서 제외했다.

.DS_Store
/Personal Access Token/
/google로그인기능/

커밋 전에는 항상 git status로 무엇이 스테이징됐는지 확인하고, 파일명만으로 안심하지 않고 내용을 직접 열어본다.
