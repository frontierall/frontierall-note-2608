yt-dlp로 영상 다운로드 시 "HTTP Error 403: Forbidden"

출처 · 온누리미션 프로젝트 (영상 다운로드 스크립트)

증상

Claude Code로 영상 다운로드 스크립트를 실행했는데 아래 오류와 함께 다운로드가 실패했다.

ERROR: unable to download video data: HTTP Error 403: Forbidden

원인

설치되어 있던 yt-dlp가 2026.7.4 구버전이었다. YouTube는 영상 스트림 URL의 서명(signature)·포맷 목록 로직을 자주 바꾸는데, yt-dlp가 이를 따라가지 못하면 서버가 요청을 비정상 접근으로 판단해 403을 돌려준다. yt-dlp 자체나 계정 문제가 아니라 버전이 YouTube의 최신 변경을 반영하지 못해서 생기는, 이 도구에서 흔한 증상이다.

판별 키워드 — unable to download video data와 함께 403 Forbidden이 뜨면 인증·권한 문제보다 먼저 yt-dlp 버전부터 의심한다. URL 자체가 잘못됐거나 비공개 영상이면 보통 403이 아니라 다른 오류 메시지(404, private video 등)가 나온다.

해결

# 현재 버전 확인
yt-dlp --version

# 최신 버전으로 업데이트
pip install --upgrade yt-dlp

2026.7.4 → 2026.8.19로 업데이트한 뒤 같은 명령을 다시 실행하자 정상적으로 다운로드됐다.

재발 방지

  • 영상 다운로드 관련 스크립트에서 403 오류가 나오면 URL이나 네트워크보다 yt-dlp --version부터 확인한다. 오래된 버전일 가능성이 가장 높다.
  • yt-dlp는 YouTube 쪽 변경에 맞춰 릴리즈가 잦은 도구다. 오래 안 쓰다가 다시 쓸 때는 실행 전에 pip install --upgrade yt-dlp로 먼저 업데이트하는 습관을 들인다.
