## PART 자료 그룹화 기준

각 PART `index.html`의 "자료" 섹션은 항목이 **5개 미만이면 단일 목록**으로, **5개 이상이면 주제별 소그룹**(`subgroup-label`)으로 나눕니다. 이어서 순서대로 따라가야 하는 실습은 그룹 라벨에 "· 순서대로"를 붙이고 카드에 `<span class="step">` 번호 배지를 넣습니다. 예시: [07_LLM_RAG_Agent](07_LLM_RAG_Agent/index.html), [02_바이브코딩](02_바이브코딩/index.html).

각 폴더 커리큘럼(학습목표·세부 항목)은 폴더 안 `index.html` / `README.md`에서 확인할 수 있습니다.
[00_사전학습](00_사전학습/index.html)은 PART가 아니라, 개강 전에 미리 보고 오면 좋은 자료(준비 체크리스트·영상)를 모아 둔 곳입니다. 추가 방법은 [해당 README](00_사전학습/README.md)에 정리해 두었습니다.
[용어사전](용어사전/index.html)은 PART 02~07 전체를 아우르는 참고 자료라서 별도 최상위 카테고리로 두었습니다. PART × 성격 2단계로 걸러 볼 수 있고, 추가 방법은 [해당 README](용어사전/README.md)에 정리해 두었습니다.
[수강생깃허브](수강생깃허브/index.html)는 수강생이 수업 중에 직접 공유한 GitHub 계정을 모아 둔 곳입니다. 공개 페이지라서 이름은 가운데 글자를 가려 적고, 명단은 `members.js` 한 파일에만 둡니다. 추가·삭제 방법은 [해당 README](수강생깃허브/README.md)에 정리해 두었습니다.
[이슈로그](이슈로그/index.html)와 [팁](팁/index.html)은 PART가 아니라, 수업·다른 프로젝트를 진행하며 겪은 문제·해결 방법과 작업 노하우를 모아두는 별도 카테고리입니다. 각각 카테고리 탭과 검색으로 필터링할 수 있습니다.
