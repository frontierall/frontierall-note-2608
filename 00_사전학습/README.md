## 자료 추가하는 법

두 자료 모두 **데이터 파일과 화면이 분리**되어 있습니다. 항목을 추가할 때 HTML은 건드리지 않습니다.

| 추가할 것 | 고칠 파일 |
| --- | --- |
| 체크 항목 | `체크리스트/checklist.js` 의 `CHECK_ITEMS` 배열에 객체 하나 추가 |
| 용어 | `용어사전/terms.js` 의 `TERMS` 배열에 객체 하나 추가 |
| 영상 | `영상/videos.js` 의 `VIDEOS` 배열에 객체 하나 추가 |

카드, 검색, 분류 탭, 개수 표시는 각 폴더의 `index.html`이 데이터를 읽어 자동으로 그립니다.
각 데이터 파일 맨 위 주석에 필드 설명이 있습니다.

용어 사전은 걸러 보는 축이 두 개입니다. 위쪽 줄은 **커리큘럼 PART**(언제 배우는가), 아래쪽 줄은 **성격**(`TERM_KINDS`: 기본 개념 / 도구 / 언어)입니다. 두 축은 함께 적용되고, 한쪽을 고르면 다른 쪽 탭의 개수가 그에 맞게 다시 계산됩니다.
PART 축을 주 분류로 삼은 이유는 이렇습니다. "이 말은 몇 주차에 나오는가"로 정리되므로 새 용어를 넣을 때 분류를 고민할 필요가 없고, 사이트 전체의 PART 체계와도 맞습니다.
새 PART의 용어를 넣을 때는 `TERM_CATEGORIES` 에 `{ id, no, name }` 한 줄을 추가하면 탭이 생깁니다. 용어가 하나도 없는 PART의 탭은 자동으로 숨겨집니다.
영상은 아직 수가 적어 성격별(`VIDEO_CATEGORIES`: 개발 환경 / 도구 입문 / 기초 개념)로 두었습니다.

체크리스트의 체크 상태는 각 수강생 브라우저(localStorage)에만 저장됩니다. 서버로 가지 않으므로 누가 체크했는지는 볼 수 없습니다.
`CHECK_ITEMS`의 `id`는 저장 열쇠이므로 **한 번 정하면 바꾸지 마세요.** 바꾸면 이미 체크해 둔 표시가 풀립니다.

### 용어 하나만 링크로 공유하기

용어마다 앵커 주소가 있습니다. `id` 값이 그대로 주소가 됩니다.

```
https://frontierall.github.io/frontierall_note_2608/00_사전학습/용어사전/#ux
```

이 주소로 들어가면 해당 용어가 펼쳐진 상태로 열립니다.

### 왜 JSON이 아니라 .js 인가

`terms.json` + `fetch()` 방식은 파일을 더블클릭해 여는 로컬 환경(`file://`)에서 브라우저 보안 정책(CORS)에 막혀 빈 화면이 됩니다.
`.js` 파일을 `<script>`로 불러오면 로컬과 GitHub Pages 양쪽에서 모두 동작합니다.

## 나중에 자료가 길어지면

특정 용어에 스크린샷·비교표가 붙어 설명이 길어지면, 그 용어만 하위 폴더(`용어사전/<id>/index.html`)로 빼고
데이터에서 링크로 연결하면 됩니다. 나머지 용어는 지금 형태를 그대로 유지합니다.
