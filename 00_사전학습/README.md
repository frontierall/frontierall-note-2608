## 자료 추가하는 법

두 자료 모두 **데이터 파일과 화면이 분리**되어 있습니다. 항목을 추가할 때 HTML은 건드리지 않습니다.

| 추가할 것 | 고칠 파일 |
| --- | --- |
| 용어 | `용어사전/terms.js` 의 `TERMS` 배열에 객체 하나 추가 |
| 영상 | `영상/videos.js` 의 `VIDEOS` 배열에 객체 하나 추가 |

카드, 검색, 분류 탭, 개수 표시는 각 폴더의 `index.html`이 데이터를 읽어 자동으로 그립니다.
각 데이터 파일 맨 위 주석에 필드 설명이 있습니다.

분류를 새로 만들려면 같은 파일의 `TERM_CATEGORIES` / `VIDEO_CATEGORIES` 에 `{ id, label }` 을 추가하면 탭이 하나 늘어납니다.

### 용어 하나만 링크로 공유하기

용어마다 앵커 주소가 있습니다. `id` 값이 그대로 주소가 됩니다.

```
https://frontierall.github.io/frontierall_note_2608/00_사전학습/용어사전/#ux
```

이 주소로 들어가면 해당 용어가 펼쳐진 상태로 열립니다.

### 왜 JSON이 아니라 .js 인가

`terms.json` + `fetch()` 방식은 파일을 더블클릭해 여는 로컬 환경(`file://`)에서 브라우저 보안 정책(CORS)에 막혀 빈 화면이 됩니다.
`.js` 파일을 `<script>`로 불러오면 로컬과 GitHub Pages 양쪽에서 모두 동작합니다.

## 나중에 자료가 길어지면

특정 용어에 스크린샷·비교표가 붙어 설명이 길어지면, 그 용어만 하위 폴더(`용어사전/<id>/index.html`)로 빼고
데이터에서 링크로 연결하면 됩니다. 나머지 용어는 지금 형태를 그대로 유지합니다.
